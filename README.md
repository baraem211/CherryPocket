# 🍒 체리포켓 (Cherry Pocket)

> **새는 돈 없이 잘 쓰기, 냉장고 파먹기까지 한 번에!**
> 1인가구 백수·취준생·사회초년생을 위한 지출 방어 웹앱

---

## 📱 앱 소개

체리포켓은 2030 세대 1인가구를 위한 **실시간 지출 매니저**입니다.  
기존 가계부가 '자산 기록'에 그쳐 이탈률이 높았던 점을 보완하여, 철저한 **지출 방어**에 집중합니다.

- **카드 실적 관리**: 전월 실적 미달로 낭비되는 카드 혜택을 최소화
- **냉장고 파먹기**: 방치된 식재료를 추적해 식비 낭비 방지
- **예산 목표 관리**: 카테고리별 예산 설정 및 달성률 시각화

---

## ✅ 구현된 기능

### 🏠 홈 대시보드
- 이번 달 총 지출 · 할인 혜택 · 고정/변동 지출 요약
- 카드 실적 현황 미니 카드 슬라이더
- 유통기한 임박 식재료 알림
- 카테고리별 도넛 차트
- 최근 지출 5건 빠른 보기

### 💳 카드 관리
- 최대 10개 카드 등록 (신용/체크 구분)
- 12개 카드사 × 카드사별 카드 목록 제공
- 카드별 이번 달 실적 진행률 (프로그레스 바)
- 주요 혜택 3가지 태그 표시
- 카드 추천 알림 (실적 미달 시 사용 유도)
- 카드 삭제 / 실적 수동 업데이트

### 🧾 지출 내역
- 월별 지출 내역 조회 (전월/다음달 네비게이션)
- 카테고리·카드·고정 등 필터 탭
- 날짜별 그룹 표시
- 월 총 지출 · 고정 지출 · 총 할인 요약 카드

### 📊 지출 통계
- 예산 대비 지출 진행률
- 카테고리별 바 차트
- 최근 3개월 지출 트렌드 라인 차트
- 카드별 할인 혜택 정리

### 🧊 냉장고 파먹기
- 냉장 / 냉동 / 실온 분류 보관
- 유통기한 D-Day 표시 (D-3 이내 주의 알림)
- 재료별 사용 완료 처리
- 재료 직접 추가 기능
- 영수증 스캔 기능 안내 (안드로이드 앱 연계 예정)

### 💰 예산 관리
- 카테고리별 월 예산 금액 설정 및 저장
- 총 예산 대비 지출 현황 히어로 카드
- 월 네비게이션으로 전월 예산 조회

### 🔔 스마트 알림
- 카드 실적 80% 이상 달성 알림
- 냉장고 유통기한 D-3 이내 임박 알림
- 헤더 알림 배지 카운트

## 🗂️ 프로젝트 파일 구조

```
/
├── index.html          # 메인 SPA HTML (모바일 앱 + 웹 레이아웃 포함)
├── css/
│   └── style.css       # 전체 스타일 (모바일 퍼스트 + 데스크톱 반응형)
├── js/
│   ├── data.js         # 앱 상수 데이터 & 유틸리티 함수
│   ├── app.js          # 모바일 앱 로직 (렌더링, API 연동, 이벤트)
│   └── web.js          # 웹(데스크톱) 전용 로직 (사이드바, 2컬럼 렌더링)
└── README.md
```

## 🗄️ 데이터 모델 (RESTful Table API)

| 테이블 | 설명 | 주요 필드 |
|--------|------|-----------|
| `cards` | 등록 카드 | card_name, card_type, performance_limit, performance_current, benefit_1~3 |
| `expenses` | 지출 내역 | amount, category, date, card_id, is_fixed, discount_amount |
| `budgets` | 월별 예산 | category, month, budget_amount |
| `fridge_items` | 냉장고 식재료 | name, category, storage_type, expire_date, is_used |
